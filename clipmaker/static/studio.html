Handheld & touch

D-pad / left stick: focus controls · A: press a focused button · X: play/pause · LB/RB: seek 5 seconds · B: close a side panel. Controls work only while this app is focused. Windows must expose the controller as a standard gamepad.

Editing

Projects autosave after changes. Originals are linked, never moved or overwritten.

Keyboard: Space play/pause · Ctrl+S save · Ctrl+Z undo · Ctrl+Shift+Z redo · Ctrl+K split · Delete remove · M bookmark.

Language models

Connection

Checks run only when requested. Listed models are not necessarily loaded.

Keys are encrypted for your Windows account and never returned to the browser. Changing the endpoint clears its old key. Load local models in LM Studio or Ollama; this page does not automatically load or unload them.

Speech & captions

Whisper runs locally. No LLM or paid transcription API is needed.

Model files ending in .en.bin recognize English only. Use a multilingual model for Japanese or other languages. Download models from the official whisper.cpp project.

Runs offline using bundled WeSpeaker. Each track keeps the original mix during that speaker’s turns. Simultaneous voices share an overlap track; background and uncertain speech are kept separately.
